## 3. 사전심의 — 대상 아님

- **결론** 현재 병원 자체 홈페이지는 의료법 제57조 사전심의 대상이 **아닙니다.**
- **근거** 심의 대상 인터넷 매체의 기준은 "직전 3개월간 일일 평균 이용자 수
  10만 명 이상"이며, 병원 자체 홈페이지는 해당하지 않습니다.
- **단, 제56조의 금지 조항은 매체와 무관하게 전부 적용됩니다.**
