# 웹사이트 품질 평가 기준 13항목

어떤 사이트가 "고급스러운가"를 감으로 말하지 않기 위한 체크리스트입니다.
**1~8은 눈에 보이는 표면, 9~13은 보이지 않는 기반**입니다. 표면만 좋은 사이트는
처음 3초만 좋고, 기반만 좋은 사이트는 아무도 기억하지 않습니다.

각 항목 10점, 총 130점 만점.

| 점수대 | 상태 |
| --- | --- |
| 9~10 | 이 항목이 사이트의 강점. 경쟁사와 구분되는 지점 |
| 7~8 | 제대로 되어 있음. 굳이 손댈 필요 없음 |
| 5~6 | 작동은 하지만 평범함. 개선 여지 큼 |
| 3~4 | 눈에 띄는 결함이 있음 |
| 0~2 | 없거나 망가져 있음 |

---

## 표면 — 보이는 것

### 1. 관점 (Point of View)

이 사이트만의 시각이 있는가. 업종 평균에서 얼마나 떨어져 있는가.

- 같은 업종 사이트 5개와 나란히 놓았을 때 구분되는가
- 그 차이가 **취향이 아니라 근거**에서 나왔는가 (이 병원이 실제로 잘하는 것, 실제 원칙)
- 시각적 모티프가 있다면 끝까지 일관되게 쓰였는가, 아니면 한두 번 쓰고 말았는가

> **감점 신호** — 템플릿을 색만 바꾼 느낌, 어떤 업종에 갖다 써도 되는 디자인

### 2. 타이포그래피

- 서체가 **역할별로** 구분되는가 (제목/본문/보조). 2종 이내가 원칙
- 크기 단계(type scale)가 명확한가. 제목과 본문 크기가 너무 가까우면 위계가 죽음
- 한글: `word-break: keep-all` 적용, 본문 행간 1.7~1.9, 한 줄 40자 이내
- 큰 제목의 자간을 좁혔는가 (한글은 기본 자간이 넓어 큰 크기에서 흩어짐)
- 반응형: `clamp()` 등으로 화면 폭에 따라 자연스럽게 변하는가

> **감점 신호** — 제목 한 단어만 색/굵기 강조, 모든 라벨이 대문자 영문, 본문이 15px 미만

### 3. 색상

- 팔레트가 **주제에서 나왔는가**. 업종 상투색(치과=하늘색, 법률=남색)을 관성으로 쓰지 않았는가
- 토큰이 정의되어 있고 일회성 색상값이 없는가
- **대비 실측**: 본문 텍스트 4.5:1 이상, 큰 텍스트 3:1 이상 (WCAG AA)
  - 배경색이 두 종류면 **두 배경 모두에서** 측정할 것
- 색만으로 정보를 전달하는 곳이 없는가

> **측정 방법** — 브라우저 콘솔에서 대비비를 직접 계산하거나 DevTools 접근성 패널 사용

### 4. 위계

- 제목 레벨(h1~h3)이 시각적 크기가 아니라 **문서 구조**를 따르는가
- `h1`은 페이지당 1개인가
- 푸터·사이드바 제목이 본문 제목과 같은 레벨로 올라가 있지 않은가
- 섹션 간 여백 리듬이 일정한가. 빈 공간이 의도인지 사고인지 구분되는가
- 강한 요소(짙은 면, 큰 사진)가 페이지당 1~2개로 절제되었는가

### 5. 이미지

- 실제 사진인가, 스톡인가, 없는가
- 해상도·비율이 일관되고 잘린 부분이 어색하지 않은가
- `alt` 텍스트가 **내용을 설명**하는가 (파일명이나 "이미지" 같은 무의미한 값이 아닌가)
- 지연 로딩과 크기 지정으로 레이아웃이 밀리지 않는가
- 저작권이 명확한가 (자체 촬영 / 라이선스 구매 / 직접 제작)

> **감점 신호** — 남의 사이트에서 가져온 사진, 얼굴이 어색한 AI 생성 이미지, 플레이스홀더 방치

### 6. 애니메이션

- **"절제"와 "안 만듦"은 다르다.** 의도한 순간이 하나라도 있는가
- 사용자 행동(열기·닫기·확인)에 반응하는 모션이 있는가
- `prefers-reduced-motion` 을 존중하는가
- 스크롤할 때마다 섹션이 올라오는 연출은 오히려 감점 (AI 생성 티가 남)

### 7. 모바일

- 360~430px 폭에서 가로 스크롤이 생기지 않는가 (`scrollWidth <= innerWidth`)
- 탭 타깃 최소 44×44px. 특히 **전화·예약 같은 핵심 동작**
- 핵심 행동이 엄지로 닿는 위치에 있는가 (하단 고정 바 등)
- 고정 헤더가 화면을 과하게 먹지 않는가
- 실제 기기 폭에서 확인했는가 (창 크기 조절이 안 되면 iframe 으로라도)

### 8. 디테일

마감의 총합. 하나하나는 작지만 없으면 "덜 된 사이트"로 읽힙니다.

- [ ] 파비콘이 기본값이 아닌가
- [ ] og:image 가 있는가 (카카오톡·네이버 공유 시 썸네일)
- [ ] 404 페이지가 디자인되어 있는가
- [ ] `sitemap.xml`, `robots.txt`
- [ ] 브라우저 탭 제목이 페이지마다 다른가
- [ ] 포커스 링이 보이는가
- [ ] 린트·타입 오류 0건

## 기반 — 보이지 않는 것

### 9. 카피(문안)

디자인보다 글이 먼저 읽힙니다. 문장 하나로 사이트 전체가 싸구려가 될 수 있습니다.

- 업종 상투구가 없는가 ("최고의 의료진", "고객 감동", "믿음과 신뢰")
- **구체적인가.** "첨단 장비" 대신 "3차원 CT로 신경관 위치를 확인합니다"
- 버튼이 **일어날 일**을 말하는가 ("제출" 대신 "예약 문의 보내기")
- 사용자가 실제로 궁금해하는 것에 답하는가 (기간, 과정, 주의사항)
- 과장·보장 표현이 없는가 (의료·금융은 법적 문제로 직결)

### 10. 성능

- 렌더를 막는 외부 요청이 몇 건인가. **폰트는 셀프 호스팅이 원칙**
- LCP 2.5초 이내, CLS 0.1 이하
- 이미지가 적절한 포맷·크기로 서빙되는가
- 불필요한 JS 번들이 없는가 (정적 페이지는 정적으로)

> **측정 방법** — `performance.getEntriesByType('resource')` 로 외부 요청 확인, Lighthouse

### 11. 접근성

대비·포커스·키보드·의미구조. **배려의 총량이 그대로 드러나는 지표**입니다.

- `lang` 속성이 맞는가
- 본문 바로가기(skip link)가 있는가
- 키보드만으로 모든 기능에 도달 가능한가
- 의미 있는 태그를 쓰는가 (`dl/dt/dd`, `nav`, `figure` 등 `div` 남발 금지)
- 모달·메뉴에 포커스 관리와 `aria-expanded` 가 있는가
- 이미지 `alt`, 폼 `label`

### 12. 신뢰 근거

특히 병원·금융·법률. **"예뻐 보임"과 "믿을 만해 보임"은 다릅니다.**

- 실명·자격·경력이 검증 가능한 수준으로 적혀 있는가
- 실제 공간 사진이 있는가
- 주소·전화가 실재하고 지도로 확인되는가
- 법정 고지 정보 (의료기관 개설자, 사업자등록번호, 개인정보처리방침)
- 구조화 데이터(JSON-LD)로 검색엔진이 이 정보를 읽을 수 있는가

### 13. 전환 설계

- 핵심 행동까지 **몇 번 눌러야 하는가**
- 그 행동이 모든 화면에서 도달 가능한가
- 경로가 하나뿐인가, 선택지가 있는가 (전화 / 온라인 예약 / 메신저)
- 지금 상태를 알려주는가 (진료 중 / 마감 / 오늘 휴진)

## 자가 점검 스크립트

브라우저 콘솔에 붙여 넣으면 3·4·7·8·11번 항목의 상당 부분을 한 번에 확인합니다.

```js
(() => {
  const hex = h => { h = h.replace('#',''); return [0,2,4].map(i => parseInt(h.substr(i,2),16)); };
  const L = c => { const s = c.map(v => { v/=255; return v<=0.03928 ? v/12.92 : ((v+0.055)/1.055)**2.4; });
                   return 0.2126*s[0] + 0.7152*s[1] + 0.0722*s[2]; };
  const ratio = (a,b) => { const [x,y]=[L(hex(a)),L(hex(b))]; const [hi,lo]=x>y?[x,y]:[y,x];
                           return ((hi+0.05)/(lo+0.05)).toFixed(2); };

  console.log('제목 구조:', [...document.querySelectorAll('h1,h2,h3')]
    .map(h => h.tagName + ':' + h.textContent.trim().slice(0,16)).join(' / '));
  console.log('h1 개수:', document.querySelectorAll('h1').length, '(1이어야 함)');

  console.log('렌더 차단 외부 CSS:', [...document.querySelectorAll('link[rel="stylesheet"]')]
    .filter(l => !l.href.startsWith(location.origin)).length, '건 (0이 목표)');
```
